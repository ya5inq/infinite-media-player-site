Télécharger Infinite Media Player

Voici le fichier de l'application pour Android TV et Fire TV. Il est signé avec la clé de publication — la même que celle qui ira dans le Google Play et l'Amazon Appstore : l'installer ici, puis le mettre à jour depuis le magasin, ne posera aucun problème.

L'application est gratuite et ne demande aucun compte de l'éditeur : elle utilise le compte de votre fournisseur.

🇫🇷 Le bon fichier

Ce n'est pas deux applications. C'est la même application, compilée deux fois : une fois pour les processeurs 64 bits, une fois pour les processeurs 32 bits. N'installez qu'un seul fichier — celui qui correspond à votre télévision.

La même application, deux architectures.
FichierPour quiTaille
arm64.apk Android TV, Fire Stick 64 bits — la plupart des modèles 32,9 Mo
armv7.apk Fire Stick 32 bits — les modèles d'entrée de gamme 29,7 Mo

Pour savoir lequel choisir, sur la télé :

adb shell getprop ro.product.cpu.abi
`arm64-v8a` → le premier ; `armeabi-v7a` → le second.

Les sommes de contrôle sont publiées avec les fichiers : SHA256SUMS.

🇫🇷 Le lien court

Les fichiers ci-dessus sont à la racine du site, sous des noms courts : sur une télévision, une adresse se tape à la télécommande, et chaque caractère compte. Ce sont les mêmes fichiers, aux octets près.

L'adresse complète est ya5inq.github.io/infinite-media-player-site/arm64.apk ; Downloader accepte de la taper sans le préfixe https://.

🇫🇷 L'installer

Sans ordinateur : l'application « Downloader »

Fire TV et Fire Stick n'ont pas de magasin d'applications hors Amazon : l'application Downloader (par AFTVnews, sur l'Amazon Appstore) est celle qui sert à installer un fichier téléchargé.

  1. Sur la télé : *Rechercher* → Downloader → *Télécharger*. Ne l'ouvrez pas encore.
  2. *Paramètres → Applications → Gérer les applications installées → Downloader → Installer des applications inconnues → Autoriser. (Fire OS 8 : la question est posée au moment d'installer ; sur les autres versions, ce réglage doit être donné à l'avance.)
  3. Ouvrez Downloader → Enter URL → tapez ya5inq.github.io/infinite-media-player-site/arm64.apk → Download.
  4. Le fichier atterrit dans Downloader / Downloads. Ouvrez-le : Android demande l'autorisation d'installer, puis l'installation démarre.

La même chose, sans installer Downloader : l'application Files de la télé peut aussi installer un APK téléchargé par le navigateur.

Depuis le téléphone

Le téléphone peut servir de clavier à la télévision, ou lui envoyer directement le fichier.

  1. Sur le téléphone, installez l'application officielle Amazon Fire TV (Google Play, gratuit). Le téléphone et la télévision doivent être sur le même réseau Wi-Fi.
  2. Sur la télé, ouvrez Downloader et laissez la case Enter URL prête à recevoir du texte.
  3. Dans l'application du téléphone, tapez l'adresse ya5inq.github.io/infinite-media-player-site/arm64.apk : elle s'écrit dans la case de la télévision. Validez, puis Download.
  4. Le fichier atterrit dans Downloader / Downloads. Ouvrez-le : Android demande l'autorisation d'installer, puis l'installation démarre.

Pour lui envoyer le fichier plutôt qu'une adresse : Apps2Fire (Google Play) l'envoie à la télévision et l'installe ; Send files to TV le dépose dans les téléchargements de la télévision, où l'application Files l'ouvre et l'installe — il faut alors autoriser Files à « Installer des applications inconnues ».

Sur iPhone et iPad — l'application officielle Amazon Fire TV existe aussi sur l'App Store : c'est elle qui sert de clavier à la télévision. Pour envoyer le fichier, la même application « Send files to TV » se trouve sur les deux boutiques (App Store : Send files to Android TV ; Google Play : Send files to TV) : installez-la sur le téléphone et sur la télévision, puis partagez le fichier depuis le téléphone.

Par câble USB — sur la télé, *Paramètres → My Fire TV → Developer options* → USB debugging à On (Fire OS), ou *Paramètres → À propos* puis sept fois sur le numéro de version (Android TV). Branchez, acceptez l'empreinte sur l'écran, puis :

adb install -r arm64.apk

Sans câble — sur Fire OS, avec ADB debugging activé :

adb connect 192.168.1.42:5555      # l'adresse de la télé
adb install -r arm64.apk

Sans adb — copiez le `.apk` sur une clé USB et ouvrez-le avec le gestionnaire de fichiers de la télé. Android refuse par défaut d'installer une application venue de l'extérieur : il faut *Paramètres → Sécurité → Sources inconnues*, et, sur Fire OS et Android TV, cette autorisation se donne par application (Unknown sources, dans les détails de l'application qui ouvre le fichier).

Une fois installée, l'application apparaît dans la liste des applications de la télévision, avec sa bannière. Elle se pilote à la manette.

🇫🇷 Et sur les autres plateformes ?

  • Téléphone et tablette Android — le Google Play.
  • Fire TV — l'Amazon Appstore.
  • iPhone et iPad — l'App Store.
  • Windows — le Microsoft Store.
  • macOS — en dehors de l'App Store : le Mac App Store exige le bac à sable, que l'application ne peut pas respecter. Le fichier est signé et notarisé.

🇬🇧 English version

The Android TV and Fire TV build of Infinite Media Player is available here as a signed APK. It is signed with the release key — the very same key the Google Play and Amazon Appstore builds use — so installing it now and updating it from a store later causes no problem.

The application is free and asks for no account with the publisher: it uses the account of your own provider.

Two files, one per architecture: arm64.apk (32.6 MB — most Android TV devices and Fire TV sticks) and armv7.apk (29.4 MB — 32-bit Fire TV sticks). To know which one your device needs: adb shell getprop ro.product.cpu.abi — arm64-v8a or armeabi-v7a. Checksums are published alongside the files: SHA256SUMS.

These are not two applications. It is the same application, compiled twice: once for 64-bit processors, once for 32-bit processors. Install only one file — the one that matches your television.

Install it with adb install -r over USB, with adb connect over the network, or from a USB stick — the last one requires allowing unknown sources for the file manager on the device.

Short links, for typing on a TV remote — the very same files: ya5inq.github.io/infinite-media-player-site/arm64.apk and ya5inq.github.io/infinite-media-player-site/armv7.apk. On a Fire TV, install the Downloader app from the Amazon Appstore, then Enter URL.

From your phone — install the official Amazon Fire TV app (Google Play, free); the phone and the television must be on the same Wi-Fi network. Open Downloader on the television, leave its Enter URL field ready, and type ya5inq.github.io/infinite-media-player-site/arm64.apk in the phone app: the text appears on the television. To send the file instead of an address, Apps2Fire sends it and installs it, and Send files to TV drops it into the television's downloads, where the Files app opens and installs it (allow Files to "install unknown apps").

On iPhone and iPad — the official Amazon Fire TV app is on the App Store too, and it is the one that acts as the television's keyboard. To send the file, the same application is on both stores (App Store: Send files to Android TV ; Google Play: Send files to TV) — install it on the phone and on the television, then share the file from the phone.
